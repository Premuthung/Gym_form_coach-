# Gym Form Coach

Take a photo of a gym machine, read how to use it, then upload a short video of one set to get a rep
count, a score out of 100 and what to fix.

This is a test version. Use the **Feedback** button in the app to tell us what worked and what did not.

Source code and documentation: <https://github.com/Premuthung/Gym_form_coach->
